# Headless TUI Replay Baseline — 2026-04-27

## Summary

This report is the first measured output from the M2 performance-evidence harness. It characterizes deterministic, headless `yach-ui` app/event/render replay workloads through `crates/yach-bench/benches/tui_latency.rs`.

**Measurement class:** headless proxy / component evidence.

These numbers measure synthetic event handling plus render-buffer completion into ratatui's `TestBackend`. They do **not** measure terminal emulator paint, PTY I/O, backend process launch, model/auth setup, real input device latency, or same-machine Pi behavior. They should not be used as PRD-facing user-perceived latency evidence without live-terminal follow-up.

## Timing boundaries

For each replay step, the headless harness starts timing immediately before applying a synthetic step and stops after rendering the updated app state into a ratatui `TestBackend` buffer.

Included:

- `yach-ui::BenchmarkApp` event handling via the same app methods used by the TUI loop.
- Transcript/prompt/tool state mutation for synthetic protocol-native events.
- Layout rendering through `layout::render` into a headless test backend.

Excluded:

- Real terminal draw/flush and terminal emulator paint.
- Tokio runtime scheduling in the production TUI loop.
- Backend adapter process startup, Pi RPC traffic, model/auth setup, network calls.
- Human input device timing and OS event delivery.

## Claim supported

This report supports a limited component-level claim:

- Yach now has repeatable headless TUI replay workloads for keypress, active stream, heavy tool output, paste, and transcript viewport characterization.
- In headless proxy measurement on this machine, simple idle keypress render is sub-millisecond and 100 KiB paste handling is low-single-digit milliseconds.
- Long transcript viewport rendering appears to scale with transcript size; 10,000 entries measured around 16.6 ms for this synthetic replay.

## Confidence and limitations

- **Confidence:** Good for detecting regressions in deterministic `yach-ui` app/event/render costs on the same machine/profile.
- **Limitations:** Not user-perceived latency. No terminal flush, PTY, live event stream, or Pi comparison. Active-stream replay is sequential and does not yet model backend queue depth or arrival-rate backlog. Criterion output is central-tendency oriented; this report does not claim p95/p99 user-facing latency.
- **Sample count:** 30 Criterion samples. Some workloads reported outliers or target-time warnings; future runs should consider longer measurement time for active-stream 1,000 and transcript 10,000 workloads.
