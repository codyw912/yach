# Yach documentation

| Path | What it is |
| --- | --- |
| `project/roadmap.md` | Product direction: vision, non-goals, milestones, principles. Read-only mirror of decisions made elsewhere. |
| `protocol/yach-proto-v0.md` | The UI/backend protocol contract (`ClientEvent`/`ServerEvent` over JSONL). |
| `benchmarks/` | Benchmark methodology and dated measurement reports; `yach-bench` writes here. |
| `project/specs/` | Accepted design documents, one per nontrivial feature. |
| `project/plans/` | Numbered implementation plans that execute those specs. |
| `project/records/` | Dated research, measurements, and decision records. |

The original product thesis is [`PRD-v0.1.md`](../PRD-v0.1.md) at the
repository root. Contributor conventions are in [`AGENTS.md`](../AGENTS.md).

Specs and plans are historical once implemented; the code and its tests are
the current contract. Records are evidence, not instructions.

## Retired paths

Historical specs, plans, and records may cite `docs/project/state.md`,
`docs/project/next.md`, `docs/project/board.md`, `docs/project/README.md`,
`docs/plans/`, `docs/project-os/`, `docs/archive/`, `docs/status/`,
`docs/spikes/`, or `docs/brainstorms/`. Those were in-repo planning surfaces
retired on 2026-09-03; the citations are left as written because they record
what those documents said at the time. Their content is available from
version control history and is not current guidance.
