# Decision Template

Add concise decisions to `../decisions.md`. Use a separate ADR-style file only when the decision needs substantial analysis.

```md
### DYYYYMMDD-NN — <Decision title>

- **Status:** proposed | accepted | superseded | revisit
- **Date:** YYYY-MM-DD
- **Context:** <What forced this choice?>
- **Decision:** <What are we doing?>
- **Rationale:** <Why this option over alternatives?>
- **Consequences:** <What becomes easier/harder?>
- **Related docs:** <Links to PRD, plan, checkpoint, code, issue>
- **Follow-up:** <Optional next action>
```

Good decision entries are short, source-linked, and specific enough that a future agent can tell whether a later change supersedes them.
