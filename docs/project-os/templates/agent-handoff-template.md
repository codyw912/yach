# Agent Handoff Template

Use this when a final handoff needs structure.

```md
## Handoff — <task/title>

- **Status:** complete | partial | blocked
- **Files changed:** <paths>
- **Checks run:** <commands or `none -- docs-only`>
- **Project OS updates:** <docs updated, or why none were needed>
- **Decisions made:** <decision IDs or none>
- **Evidence added:** <compat/perf evidence links or none>
- **Invariants touched:** <IDs or none>
- **Remaining blockers/follow-up:** <items>
```

Keep this concise. The goal is to make the next agent safe, not to narrate the whole session.
