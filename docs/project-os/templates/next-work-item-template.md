# Next-Work Item Template

Use this shape when adding items to `../next-work.md`.

```md
| Priority | Item | Status | Owner/source | Why next | Done when | Freshness / notes |
|---|---|---|---|---|---|---|
| P<N> | <Short task name> | planned / in-progress / blocked / deferred | <owner or source doc> | <Why this belongs here now> | <Observable completion condition> | <Last updated, stale-source warning, blockers> |
```

For agent-proposed work, put it under Candidate work until an owner decision or source doc promotes it.
